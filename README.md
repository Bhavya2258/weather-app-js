# Weather App

A beginner-friendly weather application built using HTML, CSS, and JavaScript.

## Features

* Search weather by city name
* Display current temperature in Celsius
* Show weather condition and icon
* Responsive and clean user interface
* Fetches live weather data using WeatherAPI

## Technologies Used

* HTML
* CSS
* JavaScript
* WeatherAPI

## How It Works

1. Enter a city name.
2. Click the **Get Weather** button.
3. The application sends a request to WeatherAPI.
4. Current weather information is displayed on the page.

## API Used

WeatherAPI: http://api.weatherapi.com
